# Wikipedia Edit Rate Analysis

## Project Overview
Can the rate at which a Wikipedia article is edited serve as a proxy for its truthfulness or reliability?

This project analyzes Wikipedia edit history data to investigate whether highly edited articles tend to be more accurate and trustworthy than articles with fewer edits. The analysis explores relationships between edit frequency, article characteristics, and indicators of reliability.

## Research Question
Does edit frequency provide useful information about the truthfulness or reliability of a Wikipedia article?

## Motivation
Wikipedia is one of the most widely used sources of information on the internet. Understanding whether public editing behavior can indicate article reliability could help users assess the trustworthiness of content more effectively.

## Key Findings
In initial edit rate spikes articles are more likely to be focused on truth finding

Secondary spikes near an initial spike indicate vandalism

More controversial/political topics had more of these secondary spikes further proving the analysis
